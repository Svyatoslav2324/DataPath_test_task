Краткое руководство по использованию

Что делает:
- Утилита внешней сортировки: читает файл с числами и записывает отсортированный результат в выходной файл.

Сборка:
- В корне репозитория выполните:
  - `cmake -S . -B build`
  - `cmake --build build -- -j$(nproc)`
  Или, если `build` уже есть:
  - `make -C build -j$(nproc)`

Запуск:
- Формат: `./build/sorter <input-file> <output-file>`
- Пример: `./build/sorter input.txt output.txt`

Конфигурация:
- Программа читает настройки из `config.txt` (лимит памяти и параметры лент).

Формат входа/выхода:
- По одному числу на строку; пустые или некоректные строки принмаются за 0.

Ошибки:
- Все сообщения об ошибках выводятся в stderr.
